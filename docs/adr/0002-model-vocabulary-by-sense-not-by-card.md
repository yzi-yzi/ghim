# Model vocabulary by sense, not by card

Ghim's durable Learner-owned unit is a Vocabulary Item identified by one Lexical Unit and one Sense, with multiple Vocabulary Encounters and accepted Learning Material. Practice Prompts are derived presentations, while each Practice Direction owns a separate Memory Track; this prevents repeated captures, deck memberships, context edits, or regenerated content from duplicating or erasing learning state.

## Consequences

Shared Lexical Evidence, Generated Enrichment, and Learner-owned material remain separate. Recognition is enabled by default and Production is opt-in; ambiguous enrichment requires confirmation, Sense changes split into a new item, and only Ready Items enter review. Decks organize items without owning them, and archive/delete remain distinct from removing a Deck Membership.
