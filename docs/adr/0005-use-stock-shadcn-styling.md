# Use stock shadcn styling with the Ghim palette

Ghim will keep the generated shadcn `base-nova` typography, spacing, radius, shadows, motion and component variants unchanged, customizing only semantic color values. This supersedes the custom Vintage Library styling clause in ADR 0004: a stock component language lowers design-system maintenance and keeps the product familiar, while the existing forest, cream and muted warm palette preserves Ghim's identity.
